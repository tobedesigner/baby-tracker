# 後續規劃

已經做完的不列。每項後面是工作量：S 半天內、M 一到兩天、L 三天以上。

## 等資料進來再做

- **生長曲線升級**（M）：WHO 百分位帶、頭圍、Y 軸刻度。需要在 `babies.ts` 加性別欄位。台灣兒童健康手冊用的就是 WHO 曲線，家長會直接對照健檢結果。等第一批健檢數字進來、有真實資料可以對再做。

## 第二階段：分享與閱讀體驗

1. **單筆永久連結**（S）：卡片加「複製連結」，貼到 LINE 直接開到那筆。網址格式見下方。
2. **PWA 與分享預覽**（S）：manifest、主畫面圖示、theme-color、og:image。阿公阿嬤加到手機桌面後像 app 一樣開。
3. **時間軸導覽**（S）：回頂端按鈕、年份與月份跳轉、時間軸上標「今天」的位置。超過五十筆再做。
4. **發展里程碑清單**（M）：翻身、坐、爬、站、走、長牙、叫爸媽這類標準項目做成清單，雙寶並排顯示達成日期，點了跳到時間軸那筆。里程碑資料加一個選填欄位對應清單項目。
5. **側欄小資訊**（S）：距離周歲還有幾天、下次健檢月齡。雙胞胎併成一列。

## 第三階段：資料入口與長期

1. **手機記錄入口**（M）：GitHub Issue 表單填一筆，Action 自動轉成資料並 commit。資料仍以 git 為準，不另架後台。
2. **疫苗時程表**（M）：台灣公費時程做成模板，對照健康分類的紀錄標出已打、下次該打。
3. **列印版型**（S）：print 樣式，周歲時可以直接印成一本或存 PDF。
4. **隱私強化**（M）：現在只靠不被搜尋收錄。選項一是靜態加密整頁、家人輸入通關密語，但照片網址仍可直接存取；選項二是搬到 Cloudflare Pages 加 Access 做 email 驗證，才是真正的權限控管。
5. **一年前的今天**（S）：資料跨年後再做。
6. **資料檔依年份拆**（S）：超過一年後把 `milestones.ts` 拆成每年一檔再合併匯出，編輯時不用捲很長。

## 網址格式

- `#uwa`、`#una`、沒有 hash：看誰。既有連結維持有效。
- 分類、標籤、搜尋：只留在記憶體，不進網址。切換看誰時保留，在新範圍裡一筆都沒有的會自動取消。
- 單筆永久連結（還沒做）：用查詢字串 `?m=<id>`，跟 hash 並存，例如 `/?m=2026-10-16-xxx#uwa`。id 要穩定，加一個選填的 `id` 欄位或用日期加標題產生，不能用陣列索引，因為新資料都插在陣列最前面。

## 決定不做的

- **換 Preact**：可以省六成 JS，但整頁 gzip 後不到 80 KB，換框架的風險不值得。
- **卡片加 content-visibility**：它隱含的 paint containment 會把畫在卡片盒子外面的時間軸圓點與卡片陰影裁掉。幾百筆之內沒必要。
- **ESLint**：typescript-eslint 還不支援 TypeScript 7，等支援了再加 react-hooks 規則。現在只有 prettier。
